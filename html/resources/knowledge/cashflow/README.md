# 캐시플로우 챗봇 참고 자료

이 폴더의 `*.md` 파일은 `App\Services\CashflowKnowledgeBase` 가 **파일명 오름차순**으로 읽어
시스템 프롬프트 뒤에 `<reference>` 블록으로 자동 주입한다. 코드 수정이나 재배포는 필요 없다.

## 넣는 방법

파일을 만들어 넣기만 하면 된다. 이름은 순서를 잡기 좋게 숫자 접두어를 권장한다.

```
resources/knowledge/cashflow/
├── README.md              <- 이 파일. 주입 대상에서 제외된다.
├── 10-기본규칙.md
├── 20-직업카드.md
├── 30-기회카드.md
└── 40-재무제표읽는법.md
```

## 규칙

- `README.md` 와 `_` 로 시작하는 파일은 주입되지 않는다. 작업 중인 초안은 `_초안.md` 로 둔다.
- 각 파일은 `<document name="파일명">` 으로 감싸져 모델에 전달된다.
  파일명이 곧 모델이 보는 자료 이름이므로 내용을 설명하는 이름을 쓴다.
- 전체 합계 상한은 `CashflowKnowledgeBase::MAX_CHARS` (기본 60,000자) 다.
  넘으면 뒤쪽 파일부터 잘리고 `laravel.log` 에 경고가 남는다. 상한은 상수만 고치면 된다.
- 표보다 짧은 문장과 목록이 모델에게 더 잘 먹는다. 카드 데이터처럼 항목이 많으면
  `카드명 / 비용 / 계약금 / 현금흐름` 형태의 한 줄 요약을 나열하는 편이 낫다.

## 주의

자료가 커질수록 매 요청 토큰이 늘어난다. 수만 자 규모로 커지면
Gemini context caching 으로 옮기는 것을 검토한다 (`CashflowKnowledgeBase` 주석 참고).
